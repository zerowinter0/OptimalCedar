# DP search validation

This directory supports the paper's scalability and exactness figure.

- `data/dp_scalability.csv` and `data/cedar_scalability.csv` contain measured
  synthetic search latency and search-space counts.
- `data/optimality_summary.json` records the exhaustive verifier result:
  100/100 random cases and 14,936,064 legal plans checked.
- `data/real_pipeline_planning.json` is the minimal immutable snapshot of the
  formal Alpaca-CoT and ArXiv plan-generation results. Cedar reached the
  300-second limit on ArXiv; PICO completed in 11.27 seconds.
- `figures/dp_search_evaluation.*` is regenerated by
  `../../../plot_search_validation.py`.

No execution-time result from the timed-out ArXiv pipeline is used.
